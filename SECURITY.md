# Security Policy

Security is a first-class Alpha Linux requirement.

## Scope

Security planning covers:

- Secure Boot and UEFI
- TPM and disk encryption
- package and repository signing
- supply-chain integrity
- dependency vulnerabilities
- SBOM generation
- secrets management
- sandboxing and permissions
- AI tool permissions
- privacy
- update integrity
- rollback and recovery
- auditability

## Reporting

A dedicated security vulnerability reporting process will be finalized before the first public release.

Do not disclose an unpatched security vulnerability publicly before coordinated remediation is available.

## Release requirement

Security checks are release gates, not optional post-release tasks.
