# Alpha Linux — Creator / Media Suite Specification

**Status:** Phase 0 normative specification
**Requirement:** AL-REQ-0020

## Scope

Photo, video, graphics, compositing, 3D, publishing, streaming, screen capture and media asset management.

## Resource integration

GPU acceleration, hardware codecs, storage throughput and memory pressure SHOULD integrate with Adaptive Resource Intelligence and System Observatory.

## Data lifecycle

Source assets MUST remain distinguishable from proxies, caches and generated outputs. Cache deletion MUST NOT delete source assets.

## Proprietary software

Vendor applications may be integrated through legal user-controlled installation paths; Alpha MUST NOT imply redistribution rights.

## Acceptance evidence

Representative media import/export, GPU acceleration detection, cache/source separation, project backup/restore, codec/device compatibility, and failure recovery.
