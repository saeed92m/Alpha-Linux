# Alpha Linux Quality Engineering

## Definition of Done

A feature is complete only when:

Requirement → Specification → Architecture → Implementation → Unit Test → Integration Test → System Test → Security Review → Documentation → Validation → Release

## Test layers

- static analysis
- unit tests
- integration tests
- packaging tests
- installation tests
- upgrade tests
- rollback tests
- hardware compatibility tests
- performance tests
- security tests
- accessibility tests
- localization tests
- recovery tests
- ISO/live-environment tests

## Release principle

A green build is not equivalent to a validated operating-system release.
