# Alpha Linux — Phase 0 Scope and Non-Goals Audit

**Status:** Phase 0 audit baseline

## In scope

- Ubuntu/COSMIC-based universal workstation experience
- Alpha system integration and management
- AI-native assistant, agents, orchestration, memory and knowledge layers
- Hardware, firmware, power, network and observability integration
- Installer, dual boot, WSL and recovery
- Package/repository and update lifecycle
- Build, CI/CD, ISO, provenance and release engineering
- Developer, scientific, engineering, astronomy, aerospace, electronics, SDR, motorsport, creator, music, office, data, cloud and other declared domain integration points
- Plugin/SDK and marketplace architecture
- Accessibility, localization, privacy and security

## Explicit non-goals for the foundation

- Reimplementing the Linux kernel
- Replacing Ubuntu's package ecosystem wholesale
- Uncontrolled Debian/Ubuntu repository mixing
- Bundling proprietary software without licensing rights
- Treating an AI model as a security or authorization authority
- Making every domain application part of the base image
- Claiming hardware support without validation evidence
- Building a full cloud service as a prerequisite for local workstation operation

## Scope control

A new capability must identify:
1. user/product value;
2. requirement family and stable ID;
3. owning subsystem;
4. dependency boundary;
5. security/privacy impact;
6. recovery impact where applicable;
7. test/validation method;
8. roadmap phase.

Unresolved scope expansion blocks Specification Freeze until dispositioned.
