# Release Channels

Alpha Linux uses staged release channels.

| Channel | Purpose | Stability |
|---|---|---|
| Development | Active engineering | Lowest |
| Nightly | Automated integration builds | Experimental |
| Alpha | Early user validation | Experimental |
| Beta | Broad pre-release validation | Pre-stable |
| Stable | Supported production release | Supported |
| LTS | Long-term support, if declared | Supported |

A channel must have explicit entry criteria, exit criteria and rollback procedures.
