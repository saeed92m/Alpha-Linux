# Linux Fundamentals

## Purpose

This chapter establishes the foundation required to understand Alpha Linux as an operating-system platform.

## Topics

- kernel vs user space;
- processes and threads;
- filesystems;
- permissions;
- users and groups;
- system calls;
- services;
- systemd;
- networking;
- device nodes;
- package management;
- logs and observability.

## Why it matters

Alpha Linux integrates and extends mature Linux foundations. Understanding those foundations prevents unnecessary reinvention and makes troubleshooting precise.

## Alpha principle

When Alpha adds a higher-level capability, the underlying Linux mechanism must remain understandable, observable and recoverable.

## بعد از این فصل باید چه چیزی بلد باشم؟

باید بتوانی توضیح بدهی یک برنامه از لحظه اجرا تا دسترسی به CPU، RAM، فایل، شبکه و سرویس‌های سیستم چگونه با Linux kernel و user space تعامل می‌کند.
