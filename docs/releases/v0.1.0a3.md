# Alpha Linux v0.1.0a3

**Verified Alpha release candidate focused on a reliable, directly published OS-image path.**

## Release identity

- Version: `0.1.0a3`
- Tag: `v0.1.0a3`
- Source: the exact successful OS-image workflow run that produced the release assets
- Channel: Alpha / prerelease

## Verified scope

- AMD64 bootable ISO
- BIOS and UEFI validation
- Live filesystem and kernel/initramfs validation
- COSMIC runtime/session validation
- QEMU boot validation
- Reproducibility and provenance evidence
- Eight ISO parts, each <=900 MiB
- SHA-256 part manifest and reassembly metadata
- Direct release publication from the validated build workspace

## Release transport

The ISO is distributed as eight individually downloadable parts to keep transport safely below large-artifact limits. Do not treat GitHub Actions artifact transport as the release source; the GitHub Release assets are the canonical downloadable assets.

## Reassembly

Download all eight `*.iso.part-01` through `*.iso.part-08` files plus the checksum, JSON metadata and `REASSEMBLE-ISO.txt`. Follow the reassembly instructions and verify the resulting ISO SHA-256 before booting it.

## Status

Alpha / Experimental. This release does not claim complete physical hardware compatibility, production installer readiness, Secure Boot readiness, Windows dual-boot readiness, or Stable/Beta status.

## Next gates

Physical installation, installer UX, hardware matrix, Secure Boot, Windows coexistence, post-install validation, recovery and Beta promotion remain explicit evidence gates.
