# Alpha Linux v0.1.0a4

**Brand-corrected Alpha release candidate for physical Live-media validation.**

## Release identity

- Version: `0.1.0a4`
- Tag: `v0.1.0a4`
- Channel: Alpha / prerelease
- Source: the exact successful OS-image workflow run that produced the release assets

## Fixes in this candidate

- Live `/etc/os-release` identifies the product as Alpha Linux.
- `.disk/info` identifies the ISO as Alpha Linux.
- GRUB/ISOLINUX Live boot labels no longer present Ubuntu as the product.
- Ubuntu installer desktop entries are hidden in favor of the Alpha Linux installer entry.
- Alpha hostname and LSB identity are applied to the Live filesystem.
- CI now extracts the produced ISO and fail-closes if Alpha identity or boot branding is missing.

## Required validation

The candidate must still pass the existing BIOS, UEFI, Live runtime, COSMIC graphical-runtime, reproducibility, provenance, checksum and release-asset gates.

Physical installation, Secure Boot, Windows coexistence, hardware compatibility and post-install validation remain separate evidence gates.
