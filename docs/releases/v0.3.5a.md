# Alpha Linux v0.3.5a

**Branding-focused Alpha OS-image release candidate.**

## Release contract

- Version: `0.3.5a`
- Tag: `v0.3.5a`
- Channel: Alpha / prerelease
- Base: Ubuntu 26.04.1 LTS
- Desktop: COSMIC
- Architecture: amd64

## Included

- Six supplied Alpha Linux desktop wallpapers.
- Supplied Alpha Linux transparent big and small logos.
- Supplied Alpha Linux COSMIC Greeter wallpaper.
- Alpha-specific asset paths that do not overwrite Ubuntu/COSMIC defaults.
- Ubuntu Desktop Bootstrap/Subiquity installation path preserved.
- Existing BIOS/UEFI, Live, COSMIC and reproducibility validation gates retained.
- Alpha identity and boot labels retained.

## Explicit non-goals

- No replacement of the upstream Ubuntu/Subiquity installer in this release.
- No deletion or overwrite of Ubuntu/COSMIC wallpaper packages.
- No replacement of the COSMIC Greeter binary.
- No risky Plymouth/firmware branding change solely for visual polish.

## Branding paths

- `/usr/share/backgrounds/alpha-linux/`
- `/usr/share/pixmaps/alpha-linux-logo-big.png`
- `/usr/share/pixmaps/alpha-linux-logo-small.png`
- `/usr/share/icons/hicolor/512x512/apps/alpha-linux.png`
- `/var/cache/systemd/home/alpha/login-background`

## Release gate

The release is publishable only after the complete OS-image workflow passes, including installer preservation, all six wallpaper checks, logo checks, Greeter fallback check, BIOS/UEFI boot smoke, Live runtime, COSMIC graphical runtime, reproducibility and artifact integrity.
