# Alpha Linux v0.1.0a2

**The second public alpha release of Alpha Linux.**

Alpha Linux v0.1.0a2 advances the project from the **v0.1.0a1 release-validation baseline** toward a reproducible, installable Alpha Linux operating system, with stronger image verification, release provenance, and automated publishing safeguards.

## ✨ Highlights

- 🖥️ **Bootable AMD64 Alpha Linux ISO**
- 🔧 **BIOS and UEFI boot validation**
- 💿 **Live environment validation**
- 🪐 **COSMIC desktop and session validation**
- ♻️ **Reproducible OS-image build and verification**
- 🔐 **Release provenance and build metadata**
- 🧾 **SHA-256 checksums for all split ISO assets**
- 🧩 **ISO reassembly metadata and instructions**
- 🛡️ **Fail-closed downstream release publishing gates**
- ⚙️ **Automated validation before release publication**

## 📦 Download

To keep CI artifact transport safely below GitHub artifact transfer limits, the ISO is distributed as eight parts of at most 900 MiB each.

**Download all ISO parts together with the following supporting files:**

- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-01`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-02`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-03`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-04`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-05`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-06`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-07`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.part-08`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.parts.json`
- `alpha-linux-0.1.0a2-alpha-amd64.iso.parts.sha256`
- `REASSEMBLE-ISO.txt`

The accompanying metadata and checksum files are part of the release contract and should be retained with the ISO parts.

Follow the instructions in **`REASSEMBLE-ISO.txt`** to reconstruct the complete ISO image before writing it to a USB drive or using it in a virtual machine.

## 🔍 Validation

The release pipeline performs automated validation of the generated OS image, including:

- BIOS boot validation
- UEFI boot validation
- Live-system validation
- Kernel and initramfs validation
- COSMIC runtime/session validation
- Image and artifact verification
- Release provenance verification
- Reproducibility checks
- Split-ISO integrity and checksum validation

Release publication is gated on successful upstream image generation and validation.

## 🚧 Release Status

**Alpha / Experimental**

Alpha Linux v0.1.0a2 is intended for **testing, validation, development, and continued platform engineering**.

It is **not yet a production-ready operating system**. Hardware compatibility, installation workflows, desktop integration, and platform functionality remain under active development.

## 🛠️ What's Next

The Alpha series will continue to strengthen the foundation of Alpha Linux toward a reliable, reproducible, installable workstation platform, with continued work across:

- Installation and upgrade workflows
