# Alpha Linux Hardware Validation

Hardware support is validated rather than assumed.

## Coverage

- CPU
- GPU
- RAM
- NVMe/SSD
- Wi-Fi
- Bluetooth
- Ethernet
- audio
- camera
- touchscreen
- pen/stylus
- keyboard
- touchpad
- fingerprint
- TPM
- external displays
- USB-C/docks
- Thunderbolt where applicable
- printers/scanners
- sensors

## Result states

- Working
- Working with limitations
- Driver required
- Unsupported
- Not tested

Hardware results must include the tested Alpha release and relevant kernel/driver versions.
