# Alpha Linux Design System

## Product identity

Product: **Alpha Linux**

Reference logo: project-owner supplied Alpha Linux product logo.

Reference palette:
- Alpha Blue: `#003C91`
- Alpha Gray: `#8A8A8A`

These colors are references, not a license to hard-code colors throughout the UI.

## Required theme modes

- Light
- Dark
- System / Auto
- Custom Theme API

Dark mode must be a deliberately designed dark interface, not a simple color inversion.

## Design-system foundations

- Design tokens
- Typography
- Iconography
- Spacing and grid
- Elevation and surfaces
- Motion and animation
- Semantic colors
- Accessibility
- RTL/LTR
- HiDPI
- Multi-display
- Touch, mouse, keyboard and pen
- Responsive/adaptive layouts

## Core Alpha UI

The design system must cover:

- Installer
- Boot and recovery
- COSMIC desktop integration
- Alpha Command Bar
- Alpha Assistant
- Alpha AI Center
- Agent activity/status
- System Observatory
- Hardware Manager
- Software Center
- Control Center
- Network Center
- Security Center
- Privacy Center
- Firmware Center
- Backup/Recovery
- Scientific and engineering workspaces

## UX principle

AI should be deeply integrated but should not make the desktop noisy, unpredictable or difficult to control.
