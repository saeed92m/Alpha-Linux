# Supply-Chain Security

Alpha Linux treats the software supply chain as a release-critical system.

## Controls

- trusted source origins;
- dependency inventory;
- package signing;
- repository authentication;
- SBOM generation;
- artifact checksums;
- artifact signatures;
- build provenance;
- isolated build environments;
- secret management;
- vulnerability monitoring;
- controlled release promotion.

## Principle

A successful compilation does not establish supply-chain trust.

Every production artifact must be traceable to approved source and build inputs.
