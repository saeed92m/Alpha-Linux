# Alpha Linux v0.3.5a branding assets

These files are additive only. They must not replace or delete Ubuntu/COSMIC defaults.

Required files:

- wallpapers/alpha-wallpaper-ai.png
- wallpapers/alpha-wallpaper-astronomy.png
- wallpapers/alpha-wallpaper-aerospace.png
- wallpapers/alpha-wallpaper-energy.png
- wallpapers/alpha-wallpaper-motorsport.png
- wallpapers/alpha-wallpaper-remote-sensing.png
- greeter/alpha-greeter.png
- logos/logo-transparent-big.png
- logos/logo-transparent-small.png

The build installs the six wallpapers under /usr/share/backgrounds/alpha-linux/,
the logos under Alpha-specific pixmap/icon paths, and the greeter image at the
COSMIC Greeter-supported per-user fallback path
/var/cache/systemd/home/alpha/login-background.

Ubuntu/COSMIC packaged wallpaper and installer assets remain untouched.
