# Definition of Done

A capability is not considered complete merely because code exists.

## Required progression

```
Requirement
→ Specification
→ Architecture
→ Implementation
→ Unit Test
→ Integration Test
→ System Test
→ Security Review
→ Documentation
→ Compatibility Validation
→ Release Validation
→ Released
```

A release-critical feature must also have:

- rollback/recovery behavior where applicable;
- observability;
- accessibility consideration;
- localization consideration;
- upgrade impact analysis;
- security/privacy assessment;
- traceability in the Master Feature Matrix.

## Quality gate

If required evidence is missing, the feature remains incomplete.
