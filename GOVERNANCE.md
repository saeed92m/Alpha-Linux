# Alpha Linux Governance

## Project principles

Alpha Linux prioritizes:

1. Correctness
2. Security
3. Reproducibility
4. Compatibility
5. Testability
6. Maintainability
7. User control
8. Documentation

## Scope control

The Master Specification and Master Feature Matrix are authoritative.

New scope after specification freeze must be introduced through a Change Request and must identify affected requirements, architecture, tests, documentation and roadmap items.

## Decision making

Significant architectural decisions are recorded in `planning/decision-log.md`.

## Releases

Release criteria are defined before implementation of the corresponding release milestone. A release must not be promoted solely because a build succeeds.
