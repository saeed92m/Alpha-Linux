# Commit Convention

Alpha Linux uses Conventional Commit-style messages.

Format:

`type(scope): summary`

Common types:

- feat
- fix
- docs
- build
- ci
- test
- refactor
- perf
- security
- chore

Examples:

- `docs(spec): define package lifecycle`
- `build(iso): add reproducible build manifest`
- `security(ai): enforce privileged-action approval`

Commits should describe one logical change whenever practical.
