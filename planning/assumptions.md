# Assumptions Register

Assumptions are explicit, reviewable and subject to validation.

| ID | Assumption | Status |
|---|---|---|
| A-001 | Alpha Linux is based on Ubuntu 26.04 LTS. | Accepted |
| A-002 | COSMIC Desktop is the primary desktop environment. | Accepted |
| A-003 | Core Alpha components should integrate mature upstream foundations rather than unnecessarily replacing them. | Accepted |
| A-004 | Phase 0 is frozen; implementation proceeds under the Phase 1 roadmap and remains subordinate to normative requirements/specifications. | Accepted |
| A-005 | Proprietary commercial applications are integrated through legal installation workflows rather than bundled without licensing. | Accepted |
| A-006 | The product must support both Light and Dark themes as first-class experiences. | Accepted |
