# Change Request Process

After Specification Freeze, changes to product scope follow this process:

1. Describe the requested change.
2. Identify affected requirements.
3. Identify affected architecture.
4. Identify security/privacy implications.
5. Identify compatibility and hardware implications.
6. Identify testing requirements.
7. Identify documentation impact.
8. Identify roadmap/release impact.
9. Record the decision.
10. Update traceability before implementation.

No material post-freeze scope change should be silently inserted into implementation.
